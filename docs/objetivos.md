# Objetivos de investigación de VIDA

Enunciados por Oziel Atlahi Montoya Mares (22 de septiembre de 2026). Son la brújula del proyecto; cada fase técnica debe poder explicarse como un paso hacia uno de ellos.

| Nivel | Pregunta |
|---|---|
| **Objetivo final de investigación** | ¿Puede existir consciencia artificial? |
| **Objetivo posterior** | Si existe, ¿qué constituye su identidad y continuidad? |
| **Objetivo de largo plazo** | ¿Puede esa continuidad mantenerse al cambiar de soporte? |
| **Objetivo extremo** | ¿Podría lograrse una forma de preservación indefinida de una mente consciente? |

## Cómo se relacionan con el trabajo actual

- VIDA-0.1 (agentes con memoria, necesidades, relaciones, aprendizaje e identidad conductual) construye el *objeto experimental* sobre el que se podrán formular estas preguntas. No responde ninguna todavía.
- El principio de interpretación científica del documento de diseño (sección 37) sigue vigente: una observación ("el agente hizo X") no es una interpretación ("es consistente con autorrepresentación") ni una hipótesis ("podría existir un mecanismo de autorrepresentación"). Ninguna de las tres demuestra consciencia. Por eso el código, los logs y las biografías describen conductas y nunca afirman estados conscientes.
- Orden previsto de aproximación: experiencia → memoria → aprendizaje → identidad → continuidad → transferencia → preservación (sección 45). Los experimentos de continuidad y transferencia (fases 4 y 5) son el primer punto donde el segundo y el tercer objetivo se vuelven medibles con el Índice de Continuidad Individual.
- El primer objetivo exige, antes que nada, criterios operativos: qué observaciones contarían como evidencia a favor o en contra. Definirlos es trabajo pendiente y previo a cualquier experimento sobre consciencia.
